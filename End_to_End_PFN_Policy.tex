\section{Problem Formulation}
\subsection{Static Network Interference Model}
\label{sec:static-model}
Let $G=(\mathcal V,\mathcal E,A)$ be a fixed, undirected pretreatment graph with $N$ nodes, where $A$ is a symmetric binary adjacency matrix and $A_{ii}=0$. Node $i$ has features $X_i$, neighborhood $\mathcal N(i)$, and degree $d_i=\sum_j A_{ij}$. For a complete allocation $\mathbf z\in\{0,1\}^N$, define
\begin{align}
K_i(\mathbf z)&=\sum_j A_{ij}z_j,
&E_i(\mathbf z)&=K_i(\mathbf z)/d_i,\\
S_i(\mathbf z)&=\ind\{K_i(\mathbf z)>\lfloor d_i/2\rfloor\}.
\end{align}
The indicator $S_i$ represents strict-majority exposure and equals zero when exactly half of the neighbors are treated. The main setting assumes $d_i>0$. For isolated nodes, we set $E_i=S_i=0$ and do not estimate causal means for majority-exposure categories without support.

\paragraph{Design-standardized response surfaces.}
To distinguish treatment indicators from the total horizon, denote the initial randomized experimental assignment by $\mathbf W$, where $W_i\overset{\mathrm{iid}}{\sim}\mathrm{Bernoulli}(1/2)$. The four treatment--exposure means for each node are
\begin{equation}
\mu_i(a,s)=\E\!\left[Y_i((a,\mathbf W_{-i}))
\mid S_i((a,\mathbf W_{-i}))=s,G,X\right],\qquad a,s\in\{0,1\}.
\label{eq:mu}
\end{equation}
Under consistency, randomization of the complete treatment vector, and $\Pr(W_i=a,S_i=s\mid G,X)>0$, this target equals the corresponding observable conditional mean. The notation $\mu_i(a,s)$ permits node-level heterogeneity. Population identification of these conditional means does not imply that a single observation on one network can precisely estimate all four means for each node. PFN prediction additionally relies on modeling and priors across nodes and tasks.

Let $\widehat\mu_i(a,s)$ denote an estimated response table, supplied by a static PFN in the original static pipeline. The predicted score, the true majority-exposure score, and the actual expected reward of a fixed allocation are, respectively,
\begin{align}
\widehat V(\mathbf z)&=\frac1N\sum_i\widehat\mu_i(z_i,S_i(\mathbf z)),\\
V_\mu(\mathbf z)&=\frac1N\sum_i\mu_i(z_i,S_i(\mathbf z)),\\
V_{\mathrm{env},\psi}(\mathbf z)&=\frac1N\sum_i m_{i,\psi}(z_i,E_i(\mathbf z)).
\label{eq:three-values}
\end{align}
Here, $m_{i,\psi}(a,e)$ is the response mean under exact neighborhood exposure in task $\psi$. The simulation model assumes that exact exposure sufficiently describes the static response. Equation~\eqref{eq:mu} averages over complete assignments within a majority-exposure category under the experimental design. Consequently, even $\widehat\mu=\mu$ does not generally imply $V_\mu=V_{\mathrm{env},\psi}$. Treating majority exposure as a sufficient response mapping requires additional assumptions. We therefore evaluate optimization of the predicted objective and actual rewards separately.

\paragraph{Budgets and allocations.}
Let $B\in\{0,\ldots,N\}$ be a treatment-count budget. Define
\begin{equation}
\mathcal Z_B^{=} =\{\mathbf z:\|\mathbf z\|_1=B\},\qquad
\mathcal Z_B^{\leq}=\{\mathbf z:\|\mathbf z\|_1\leq B\},\qquad
\mathbf z\in\{0,1\}^N.
\label{eq:budget}
\end{equation}
Write the budget mode as $\kappa\in\{=,\leq\}$. The static objective is
$\max_{\mathbf z\in\mathcal Z_B^\kappa}\widehat V(\mathbf z)$.
The vector $(0,1,0,0,1,\ldots)$ assigns treatment to nodes 2 and 5. Vector positions index nodes rather than intervention times.

The static marginal score of adding a single node is
\begin{equation}
\Delta_j(\mathbf z)=\widehat V(\mathbf z+\mathbf e_j)-\widehat V(\mathbf z),\qquad z_j=0.
\label{eq:static-marginal}
\end{equation}
This change includes node $j$'s own response and changes in its neighbors' exposures. Under an exact-count budget, comparisons between final feasible allocations use the marginal value of a one-for-one swap; an addition that violates the budget is not a feasible final action.

\subsection{Sequential Decision Extension: MDP Formulation}
\label{sec:mdp}
Let $t=0,\ldots,T-1$, with remaining horizon $L_t=T-t$ and discount factor $0<\gamma\leq1$. A complete allocation $\mathbf z_t$ is executed in each period, producing the allocation trajectory $Z=(\mathbf z_0,\ldots,\mathbf z_{T-1})$. A policy generates allocations period by period from current information, rather than generally committing to an entire open-loop trajectory at the outset. The budget $B$ resets each period; it is not a total resource stock depleted across periods.

\paragraph{One-period fatigue cost.}
Let $\mathbf f_t$ denote the previous period's allocation, with $\mathbf f_0=\mathbf0$. The state and transition are
\begin{equation}
q_t=(L_t,\mathbf f_t),\qquad
\mathbf f_{t+1}=\mathbf z_t,\qquad L_{t+1}=L_t-1.
\end{equation}
Let $R_t^{\mathrm{base}}=N^{-1}\sum_iY_{i,t}(\mathbf z_t)$. The reward is
\begin{equation}
R_t^{\text{fatigue cost}}=R_t^{\mathrm{base}}-\frac{c_f}{N}\|\mathbf f_t\|_1,\qquad c_f\geq0.
\label{eq:fatigue-cost}
\end{equation}
This definition retains the one-period history cost of the original model: the number treated in the previous period incurs a cost once in the current period. It does not automatically reduce the effect of retreating the same node or restrict that node's selection. The fatigue cost setting supports both budget modes. No additional history cost is charged after the terminal time.

\paragraph{Two-period cooldown constraint.}
Let $h_{i,t}\in\{0,1,2\}$ be the number of remaining waiting periods for node $i$, initially zero, and let $\chi_{i,t}=\ind\{h_{i,t}=0\}$ indicate availability. The state is $q_t=(L_t,\mathbf h_t)$. This setting uses an at-most-count budget and requires $z_{i,t}\leq\chi_{i,t}$. The transition is
\begin{equation}
h_{i,t+1}=\begin{cases}
2,&z_{i,t}=1,\\
\max\{h_{i,t}-1,0\},&z_{i,t}=0,
\end{cases}
\qquad R_t^{\text{cooldown}}=R_t^{\mathrm{base}}.
\label{eq:cooldown}
\end{equation}
After treatment in period $t$, a node cannot be treated in periods $t+1$ and $t+2$ and becomes available again in period $t+3$. Its neighbors do not automatically enter cooldown. The cooldown setting does not add a fatigue cost. A binary availability indicator alone cannot distinguish nodes that must wait one more period from those that must wait two.

\paragraph{Fixed action catalog and feasible actions.}
To compare exploration, planning, and policy learning in the same action space, define a nonempty catalog of distinct allocations,
\begin{equation}
\mathcal C=\{\mathbf z^{(1)},\ldots,\mathbf z^{(M)}\}\subseteq\mathcal Z_B^\kappa.
\label{eq:catalog}
\end{equation}
Action index $a_t\in\{1,\ldots,M\}$ corresponds to $\mathbf z_t=\mathbf z^{(a_t)}$. All candidates are feasible in the fatigue cost setting. In the cooldown setting,
\begin{equation}
\mathcal A(q_t)=\{a:\ z_i^{(a)}\leq\chi_{i,t}\ \forall i\},\qquad
M_t(a)=\ind\{a\in\mathcal A(q_t)\}.
\label{eq:feasible}
\end{equation}
The cooldown catalog includes the all-zero allocation, so waiting is always possible. Candidates with high static scores need not cover the dynamically optimal sequence; catalog construction should also cover different treatment counts and node combinations. The catalog, node order, and action indices remain fixed during a run. Optimality references are explicitly restricted to this action space.

\paragraph{Information conditions, causal interpretation, and value objectives.}
Within a fixed task $\psi$, the reward and next state depend only on the current state and action, yielding a finite-horizon MDP with zero value at the terminal horizon $L=0$. When the model is known, the planner receives a specified reward $r_m$ and transition $F$. The model $m=\mathrm{score}$ combines $\widehat V$ with the dynamics above, whereas $m=\mathrm{env}$ uses actual conditional expected rewards. Their values are
\begin{equation}
J_{\psi,m}(\pi)=\E_\pi\!\left[\sum_{t=0}^{T-1}\gamma^t r_m(q_t,a_t)\right].
\end{equation}
Interaction-based learning instead targets factual return:
\begin{equation}
J_\psi(\pi)=\E_{\pi,\psi}\!\left[\sum_{t=0}^{T-1}\gamma^tR_t\right].
\label{eq:return}
\end{equation}
On an unknown task, the learner observes only the current state, feasible actions, and factual records of executed actions. Budgets and cooldown availability are public constraints. An ``unknown model'' means that a complete, queryable reward--transition model is not supplied to the learner; feasible actions remain observable. When task parameters are unknown, the physical state is still Markovian within the fixed task, while history provides additional task information and should be included in the policy context.

Identification under static randomization does not automatically identify dynamic intervention effects. Combining a static score with artificial dynamic rules defines a planning model. Inferring sequential policy value from observational logs additionally requires consistency, sequential exchangeability conditional on history, positive support for the relevant complete actions, and sufficiently informative state records. Our main learning protocol permits real or simulated interaction during training. Feedback is restricted to executed actions, and potential outcomes for unselected actions are not supplied to the learner.

Let $Q_{m,L}^\pi(x,a)$ denote expected return when starting from memory state $x$ with $L$ periods remaining, executing action $a$, and following $\pi$ thereafter. Define the dynamic marginal value as
\begin{equation}
\Delta_{m,L}^\pi(x;a',a)=Q_{m,L}^\pi(x,a')-Q_{m,L}^\pi(x,a),\qquad
a,a'\in\mathcal A((L,x)).
\label{eq:dynamic-marginal}
\end{equation}
It includes immediate direct and spillover rewards, future fatigue cost, and changes in opportunities caused by cooldown. A fixed individual treatment effect cannot substitute for this quantity.

\section{Progressive Decision Framework}
\subsection{Offline Static Optimization}
\label{sec:offline}
In this setting, the response table used for decision-making is given, and actions do not change future states. When the response surface is estimated, the algorithm optimizes a predicted objective rather than known actual rewards. The exact-count search space contains $\binom NB$ allocations; the at-most-count space contains $\sum_{b=0}^B\binom Nb$.

\paragraph{Greedy construction and local swaps.}
Forward Greedy starts from the empty allocation and repeatedly adds the node with the largest marginal score in Equation~\eqref{eq:static-marginal}. It performs $B$ additions for an exact-count budget. Under an at-most-count budget, it may stop when the largest marginal gain is no longer positive. Relevant exposures are recomputed after each allocation change. Local Swap searches for feasible one-for-one exchanges from an initial allocation until no improvement exceeds a numerical tolerance. The at-most-count mode also permits single-node additions and deletions. Expanded neighborhoods may include two-node additions, two-node deletions, and two-pair exchanges, whose computational costs are reported separately. Changing a node set $C$ affects only the score terms in $C\cup\bigcup_{j\in C}\mathcal N(j)$, allowing incremental updates using treated-neighbor counts.

\paragraph{Multistart joint search.}
Each restart of the Greedy Randomized Adaptive Search Procedure (GRASP)\citep{feo1995} consists of randomized greedy construction followed by local improvement. Construction samples from a restricted candidate list,
\begin{equation}
\mathcal R_\rho=\{j:\Delta_j\geq\Delta_{\max}-\rho(\Delta_{\max}-\Delta_{\min})\},\qquad \rho\in[0,1].
\end{equation}
The exact-count mode constructs $B$ treatments, while the at-most-count mode permits different construction sizes. Each construction is refined through local swaps, and the best allocation is retained within a fixed restart count or time budget. Using the Greedy solution as the initial incumbent ensures that the returned score is no lower than that initial score, without guaranteeing strict improvement or global optimality. The action catalog can combine distinct high-scoring search outputs, allocations using different treatment counts, and a waiting action where required.

\paragraph{Exact reference.}
The majority-exposure score admits a mixed-integer linear programming (MILP) formulation. Let $\tau_i=\lfloor d_i/2\rfloor+1$, introduce binary $s_i$ for majority exposure and $u_i=z_is_i$ for the product, and impose
\begin{align}
\sum_jA_{ij}z_j&\geq\tau_is_i,&
\sum_jA_{ij}z_j&\leq\tau_i-1+(d_i-\tau_i+1)s_i,\\
0\leq u_i&\leq z_i,&u_i&\leq s_i,\qquad u_i\geq z_i+s_i-1.
\end{align}
Define $\alpha_i=\widehat\mu_i(1,0)-\widehat\mu_i(0,0)$,
$\beta_i=\widehat\mu_i(0,1)-\widehat\mu_i(0,0)$, and
$\delta_i=\widehat\mu_i(1,1)-\widehat\mu_i(1,0)-\widehat\mu_i(0,1)+\widehat\mu_i(0,0)$. The objective is
\begin{equation}
\max\frac1N\sum_i[\widehat\mu_i(0,0)+\alpha_i z_i+\beta_i s_i+\delta_i u_i],
\end{equation}
subject to the budget constraint. A result is called exact only when global optimality is certified. Time-limited runs report the best feasible value, an upper bound, and the optimality gap.

\paragraph{Limitations and progression.}
Strict-majority thresholds can produce negative single-node gains but positive joint gains. For example, consider a three-node complete graph with an at-most-count budget $B=2$ and node means $\mu_i(0,0)=0$, $\mu_i(1,0)=-1$, and $\mu_i(a,1)=10$. The empty, single-node, and two-node allocations have scores $0$, $-1/3$, and $8/3$, respectively. A Greedy method accepting only positive single-node gains stops at the empty allocation. Larger local neighborhoods and multistart search can mitigate this obstacle at additional computational cost. Static scores also leave future states unmodeled. The next setting first introduces feedback learning, followed by physical dynamics.

\subsection{Online Adaptive Exploration over an Action Catalog}
\label{sec:bandit}
With the network, budget, and catalog fixed, each complete allocation is a bandit arm. Nodes are not treated as unrelated arms. This setting has no fatigue cost or cooldown, and actions do not change subsequent physical states. The unknown means are
\begin{equation}
m_a=V_{\mathrm{env},\psi}(\mathbf z^{(a)}),\qquad R_t=m_{a_t}+\xi_t.
\end{equation}
If node-level noise is independent and distributed as $\mathcal N(0,\sigma^2)$, then $\xi_t\sim\mathcal N(0,\sigma_R^2)$ with $\sigma_R^2=\sigma^2/N$. Correlated noise requires a different aggregate variance calculation. Candidate means remain fixed within a run; only knowledge about their rewards changes.

\paragraph{UCB for continuous rewards.}
Let $n_a(t)=\sum_{u<t}\ind\{a_u=a\}$ and let $\bar R_a(t)$ be the observed sample mean. The method first visits unobserved candidates in sequence and subsequently chooses
\begin{equation}
a_t\in\arg\max_a\left\{\bar R_a(t)+c\sigma_R
\sqrt{\frac{2\log(\max\{2,t+1\})}{n_a(t)}}\right\},
\label{eq:ucb}
\end{equation}
where $c$ is selected on validation environments. This index follows the upper-confidence-bound exploration principle\citep{auer2002} and matches the Gaussian reward scale used here. We do not directly claim all theoretical results of bounded-reward UCB1 for this setting. Initial visits count toward the interaction budget. If $T<M$, only the first $T$ candidates receive an initial observation. Ties follow a predetermined rule, and candidate-permutation experiments assess the effect of initialization order.

\paragraph{Baselines and evaluation objective.}
Random samples candidates uniformly. With probability $1-\varepsilon_t$, $\varepsilon$-greedy selects the action with the largest current empirical score; otherwise, it explores uniformly. Initialization of unvisited scores must be recorded explicitly. FrozenPFN always selects $a_F\in\arg\max_a\widehat V(\mathbf z^{(a)})$ and does not update its ranking after rewards arrive. Let $m_*=\max_a m_a$. Catalog-restricted pseudo-regret is
\begin{equation}
\mathcal R_T=\sum_{t=0}^{T-1}(m_*-m_{a_t}).
\label{eq:regret}
\end{equation}
Minimizing its expectation is equivalent to maximizing cumulative expected reward over the fixed horizon. True arm means are used only for evaluation and are excluded from algorithm inputs. Observation noise does not appear directly in the pseudo-regret definition. FrozenPFN has pseudo-regret $T(m_*-m_{a_F})$, while Random has expected pseudo-regret $T(m_*-M^{-1}\sum_a m_a)$.

The history-conditioned PFN in Section~\ref{sec:pfn} also applies to this setting when physical dynamics are removed and $\gamma=1$. Its parameters remain frozen, but factual history changes its action distribution, unlike FrozenPFN's fixed ranking. A bandit formulation captures the information value of actions under unknown rewards; action-dependent physical aftereffects require an MDP formulation.

\subsection{Finite-Horizon Planning under Known Dynamics}
\label{sec:planning}
Suppose the reward model $r_m$ and transition $F_x$ are known, where $x$ is the memory state for fatigue cost or cooldown. Within the same catalog, exact dynamic programming satisfies
\begin{align}
V_{m,0}(x)&=0,\\
Q_{m,L}(x,a)&=r_m((L,x),a)+\gamma V_{m,L-1}(F_x(x,a)),\\
V_{m,L}(x)&=\max_{a\in\mathcal A((L,x))}Q_{m,L}(x,a).
\label{eq:bellman}
\end{align}
Storing values and optimal actions from $L=1$ to $T$ yields a finite-horizon policy. Ordinary planning uses the predicted-score model. The optimal policy under the true environment model is reported separately as a reference with more information.

Rolling-horizon planning expands a search tree of depth $\min\{d,L_t\}$ from the current state, uses a zero terminal value at the truncation boundary, executes only the first action, and replans in the next period. The depth $d=1$ gives myopic selection under the same model. When the depth covers the remaining horizon, it agrees with full planning. Comparisons use the return from rolling execution over all $T$ periods, rather than the local value of the truncated search tree.

\paragraph{Separability of the fatigue cost model.}
For a fixed base score $b(\mathbf z)$ and initial memory $\mathbf f_0=\mathbf0$, total value under fatigue cost can be rewritten as
\begin{equation}
J=\sum_{t=0}^{T-2}\gamma^t
\left[b(\mathbf z_t)-\gamma\frac{c_f}{N}\|\mathbf z_t\|_1\right]
+\gamma^{T-1}b(\mathbf z_{T-1}).
\label{eq:fatigue-cost-separable}
\end{equation}
Under an exact-count budget, the cost is constant across action choices, so the myopic policy maximizing $b$ in each period is already optimal. Under an at-most-count budget, nonterminal periods maximize $b(\mathbf z)-\gamma c_f\|\mathbf z\|_1/N$, and the last period maximizes $b(\mathbf z)$. Rolling planning with depth two is sufficient to choose an optimal current action. The fatigue cost model is an analytically tractable benchmark for checking history costs and terminal handling; it does not establish a general advantage for complex long-term planning.

For example, let $N=2,T=3,\gamma=1,c_f=2$, and assign base scores $0$ and $0.8$ to the zero action and a single-node action. Each treatment incurs a cost of $1$ in the next period. The optimal sequence waits for two periods and treats in the final period, attaining value $0.8$. Repeated myopic treatment attains $0.4$. These are analytically constructed values, not empirical results.

\paragraph{Intertemporal coupling through cooldown.}
Under cooldown, the current action changes the future feasible set, preventing independent maximization in each period. Consider two adjacent nodes with $B=2,T=3,\gamma=1$, and the following expected base rewards:
\begin{equation}
\begin{array}{c|cccc}
\mathbf z&(0,0)&(1,0)&(0,1)&(1,1)\\\hline
b(\mathbf z)&0&3&3&5
\end{array}.
\label{eq:cooldown-example}
\end{equation}
The myopic policy treats both nodes in the first period and can only wait thereafter, earning total value $5$. The sequence $(1,0),(0,1),(0,0)$ earns $6$. A two-period cooldown permits each node to be treated at most once within the three-period horizon, and enumeration confirms that $6$ is optimal. These rewards can be generated as the network average of $m_i(z_i,e_i)=6z_i-z_ie_i$.

\paragraph{Computational bottlenecks.}
Cooldown has at most $3^N$ memory states. Explicit dynamic programming can require $O(T3^NM)$ state--action evaluations, excluding the cost of each reward and transition calculation; the reachable state set may be smaller. A naive depth-$d$ rolling search can also expand $O(M^d)$ nodes. Exact state-by-state solution is therefore severely limited on large graphs. This motivates learning shared decision rules that shift computation from search on new instances to training across tasks.

\subsection{Amortized PFN Reinforcement Learning Policy}
\label{sec:pfn}
\subsubsection{Task Priors, Factual Context, and Method Scope}
In the core setting, the learner acquires long-term decision rules from factual interaction without reading a complete reward--transition model. A task $\psi$ comprises the graph, node features, response mechanism, dynamics type, budget, catalog, noise, and horizon. Training tasks are drawn from an explicitly specified prior $p_{\mathrm{train}}(\psi)$. Validation and test splits are defined by latent task, and different trajectories from the same task cannot leak across splits.

The available history and policy input are
\begin{equation}
\mathcal D_t=((q_u,a_u,R_u,q_{u+1},D_u):u<t),\qquad
I_t=(G,X,\mathcal C,B,\kappa,q_t,\mathcal D_t),
\label{eq:context}
\end{equation}
where $D_u$ is a termination indicator. If histories from earlier episodes of the same task are allowed, episode identifiers accompany the records. Task context is cleared when switching tasks. The model learns $\pi_\theta(a_t\mid I_t)$. During deployment, $\theta$ is fixed, and the action distribution changes only through context updates. Context approximately represents uncertainty about an unknown task; we do not claim exact Bayesian posterior inference.

To connect with the earlier approach, optional variants may read a static prediction table or initial factual samples. These are explicitly labeled experiments with additional information. The core factual-learning setting does not require running a static PFN predictor first. If catalog generation still relies on static search, its preparation cost and dependencies must be included. An end-to-end policy does not eliminate external catalog construction.

\subsubsection{Graph State Encoding and Transformer History Fusion}
Node inputs include structure, attributes, and current state:
\begin{equation}
e_{i,t}^{(0)}=\operatorname{MLP}_{\mathrm{in}}
([X_i,d_i,f_{i,t},h_{i,t},\chi_{i,t},B/N,L_t/T]).
\end{equation}
The fatigue cost setting uses $h_{i,t}=0,\chi_{i,t}=1$; the cooldown setting uses $f_{i,t}=0$. Global indicators identify the dynamics type and budget mode. In the special case without dynamics, historical state variables are set to zero. With a graph convolutional network (GCN)\citep{kipf2017}, let $\widetilde A=A+I_N$ and use
\begin{equation}
H_t^{(\ell+1)}=\operatorname{ReLU}
(\widetilde D^{-1/2}\widetilde A\widetilde D^{-1/2}H_t^{(\ell)}W_\ell).
\end{equation}
A graph attention network (GAT)\citep{velickovic2018} is an alternative that aggregates messages with learned neighbor weights. Residual connections preserve each node's own history and availability, while pooling produces a network summary.

The trajectory encoder tokenizes observed states, complete action representations, aggregate rewards, next states, termination indicators, and episode times. A Transformer\citep{vaswani2017} processes history through causal attention. The current graph state then queries the historical representation to produce node embeddings $u_{i,t}$ and a global embedding $u_{g,t}$. This extracts unknown response patterns from feedback while distinguishing physical state changes from changes in knowledge about the environment. Inputs exclude the current unobserved reward and future records. Context truncation length is reported as an experimental factor.

Graph nodes do not receive positional embeddings tied to arbitrary identifiers. Permuting nodes transforms the graph, features, state, and candidate allocations together. Candidate representations are generated from allocation content and graph structure, rather than solely from action indices. Episode-time positions distinguish feedback order. Graph encoding is permutation equivariant under synchronized relabeling, whereas autoregressive decoding additionally depends on the chosen node order.

\subsubsection{Joint Candidate Distribution and Action Masking}
The main model directly outputs a joint action distribution on the same catalog used by the planner. The base selection propensity of node $i$ is $p^0_{i,t}=\operatorname{sigmoid}(w^\top u_{i,t}+b)$, and the candidate score is
\begin{equation}
\ell_\theta(I_t,a)=\sum_i\left[z_i^{(a)}\log p^0_{i,t}
+(1-z_i^{(a)})\log(1-p^0_{i,t})\right]
+g_\theta(I_t,\mathbf z^{(a)}).
\label{eq:logit}
\end{equation}
The shared action head $g_\theta$ reads pooled treated-node embeddings, adjacency relationships among treated nodes, exposure structure, and global information. It therefore supports joint effects beyond independent node scores. The implementation uses log-sigmoid for numerical stability. Applying the mask from Equation~\eqref{eq:feasible} gives
\begin{equation}
\pi_\theta(a\mid I_t)=
\frac{M_t(a)\exp\ell_\theta(I_t,a)}
{\sum_{b=1}^M M_t(b)\exp\ell_\theta(I_t,b)}.
\label{eq:masked-policy}
\end{equation}
Normalization subtracts the largest feasible logit before exponentiation. Infeasible actions have zero probability. The final marginal selection probability for node $i$ is $\sum_a\pi_\theta(a\mid I_t)z_i^{(a)}$, which generally differs from $p^0_{i,t}$.

Training samples one complete action and stores its index, allocation vector, and joint log-probability. Reward reception and state updates occur only after execution. Deterministic deployment selects the feasible candidate with the highest score. The reported deployment evaluations use deterministic candidate selection.

\subsubsection{Autoregressive Allocation and Static and Online Special Cases}
To retain structured generation, we also consider a candidate-prefix decoding variant. Given node order $v_1,\ldots,v_N$, define
\begin{align}
\mathcal C_{t,j}&=\{\mathbf z^{(a)}:a\in\mathcal A(q_t),\ 
z_{v_\ell}^{(a)}=z_{t,v_\ell}\ \forall\ell<j\},\\
M_{t,j}(b)&=\ind\{\exists\mathbf z\in\mathcal C_{t,j}:z_{v_j}=b\},\quad b\in\{0,1\}.
\end{align}
A bitwise masked softmax generates the allocation, with complete probability
\begin{equation}
\pi_\theta(\mathbf z_t\mid I_t)=\prod_{j=1}^N
\pi_\theta(z_{t,v_j}\mid\mathbf z_{t,v_{<j}},I_t).
\label{eq:autoregressive}
\end{equation}
Starting from a nonempty feasible catalog, each step retains a prefix that can be completed, so the final allocation belongs to the same catalog. A length-$N$ decoding process is one environment action; internal prefixes are not additional factual interactions. For this variant, synchronized node permutations provide a way to vary the decoding order while preserving the underlying task.

A static generation variant over the full budget-feasible space is not restricted to a fixed catalog. If $c_j$ nodes have already been selected and $r_j=N-j$ nodes remain after the current position, the budget masks are
\begin{equation}
M_j^{=}(b)=\ind\{0\leq B-c_j-b\leq r_j\},\qquad
M_j^{\leq}(b)=\ind\{c_j+b\leq B\}.
\label{eq:budget-mask}
\end{equation}
For $T=1$ and reward $\widehat V(\mathbf z)$, this variant reduces to an offline PFN allocation policy. Without physical dynamics and with factual reward feedback, the history-conditioned policy reduces to an online PFN bandit policy. Full-space and catalog-restricted policies have different optimality references and must not be compared as if their action spaces were identical. Selecting the most probable bit at each step is constructive decoding, not global maximization of joint probability or reward.

\subsubsection{End-to-End Training across Tasks}
Shared parameters directly optimize long-term reward across tasks:
\begin{equation}
J(\theta)=\E_{\psi\sim p_{\mathrm{train}}}\E_{\pi_\theta,\psi}
\left[\sum_{t=0}^{T-1}\gamma^tR_t\right].
\label{eq:meta-objective}
\end{equation}
The graph encoder, history encoder, and action head are jointly updated through the same return objective, without differentiating binary treatments or majority thresholds. Optimization targets complete allocations and their subsequent consequences rather than nodewise counterfactual prediction errors.

Optional behavior-cloning pretraining uses heuristic or planning-expert actions on training tasks:
\begin{equation}
\mathcal L_{\mathrm{BC}}=-\E_{(I,a^{\mathrm E})\sim\mathcal D_{\mathrm E}}
\log\pi_\theta(a^{\mathrm E}\mid I).
\end{equation}
For autoregressive actions, the joint log-probability is the sum of bitwise log-probabilities. Expert initialization may improve the starting policy, but demonstrations constitute additional information. The main strict factual-trajectory experiment does not use hidden models to generate expert labels. This variant reports the source and cost of demonstrations separately.

Let $G_t=\sum_{u=t}^{T-1}\gamma^{u-t}R_u$, and let $v_\phi(I_t)$ be a value baseline independent of the currently sampled action. REINFORCE\citep{williams1992} yields
\begin{equation}
\nabla_\theta J=\E\left[\sum_{t=0}^{T-1}\gamma^t
(G_t-v_\phi(I_t))\nabla_\theta\log\pi_\theta(a_t\mid I_t)\right].
\label{eq:reinforce}
\end{equation}
This objective incorporates the influence of actions on subsequent states and information. The value baseline reduces gradient variance without introducing a separate combinatorial optimization step.

The main training procedure can use PPO\citep{schulman2017}. After collecting factual trajectories with a frozen old policy, compute the ratio using the same histories, masks, and executed actions:
\begin{align}
\varrho_t(\theta)&=\exp\{\log\pi_\theta(a_t\mid I_t)-\log\pi_{\theta_{\mathrm{old}}}(a_t\mid I_t)\},\\
\mathcal L_{\mathrm{clip}}&=-\E_{\mathrm{old}}\sum_t\gamma^t
\min\{\varrho_t\widehat A_t,
\clip(\varrho_t,1-\epsilon,1+\epsilon)\widehat A_t\}.
\end{align}
With generalized advantage estimation (GAE)\citep{schulman2016}, recurse backward within each episode:
\begin{align}
\delta_t&=R_t+\gamma(1-D_t)v_{\phi_{\mathrm{old}}}(I_{t+1})-v_{\phi_{\mathrm{old}}}(I_t),\\
\widehat A_t&=\delta_t+\gamma\lambda_{\mathrm{GAE}}(1-D_t)\widehat A_{t+1},\\
\widehat G_t&=\widehat A_t+v_{\phi_{\mathrm{old}}}(I_t).
\end{align}
Set $\widehat A_T=0$ for a complete episode. True terminal states are not bootstrapped. Truncation due to batch length uses the final state value, and advantages do not propagate across episode boundaries. The total loss is
\begin{equation}
\mathcal L=\mathcal L_{\mathrm{clip}}
+c_V\E_{\mathrm{old}}\sum_t\gamma^t[v_\phi(I_t)-\sg(\widehat G_t)]^2
-c_H\E_{\mathrm{old}}\sum_t\gamma^t\mathcal H(\pi_\theta(\cdot\mid I_t)).
\end{equation}
Advantage and value targets are detached from the computation graph. Entropy can be calculated exactly for the candidate distribution. PPO updates use the original executed action probabilities rather than resampling replacement actions. Encodings recomputed after parameter updates cannot substitute for stored old-policy probabilities. The main evaluation may use $\gamma=1$; other discount settings retain time weights consistent with the objective.

\begin{algorithm}[htbp]
\caption{Training and deploying an amortized PFN policy from factual interactions}
\label{alg:training}
\begin{algorithmic}[1]
\Require Task prior, independent validation tasks, training interaction budget, public constraint interface
\State Initialize the graph network, Transformer, action head, and value network
\For{each training iteration}
  \State Freeze old parameters; sample training tasks and initialize states and contexts
  \For{each period in a task}
    \State Encode the graph state and observed history; sample a masked complete action
    \State Execute the action; receive its factual reward, next state, and terminal flag
    \State Store history, action, feedback, and old joint log-probability; append factual context
  \EndFor
  \State Compute episode-aware advantages and targets; perform the scheduled PPO updates
\EndFor
\State Select a model using validation tasks and freeze shared parameters
\State On new tasks, infer and execute feasible allocations; adapt through factual context
\end{algorithmic}
\end{algorithm}

The REINFORCE and PPO procedures above require fresh trajectories collected by the current policy. Scheduling training before deployment does not make standard on-policy updates valid for arbitrary fixed historical logs. If only offline logs are available and further interaction is impossible, a separate offline reinforcement learning protocol is required to address behavior probabilities, action coverage, and distribution shift. Performance under that condition is outside the established scope of this procedure.

\subsubsection{Traditional Reinforcement Learning Baselines: Q-learning and Dyna-Q}
Under the same observable states, catalog, and real-interaction budget, Q-learning\citep{watkins1992} updates
\begin{align}
y_t&=\begin{cases}R_t,&D_t=1,\\
R_t+\gamma\max_{b\in\mathcal A(q_{t+1})}Q(q_{t+1},b),&D_t=0,
\end{cases}\\
Q(q_t,a_t)&\leftarrow Q(q_t,a_t)+\alpha[y_t-Q(q_t,a_t)].
\end{align}
The state includes the remaining horizon, and exploration and maximization use only feasible actions. Evaluation freezes the Q table, with a predefined fallback for unvisited states.

After each real update, Dyna-Q maintains an empirical model from factual records: visit counts $n(q,a)$, reward sample means $\widehat r(q,a)$, and joint next-state and termination frequencies $\widehat P(q',D\mid q,a)$. It then samples $K_{\mathrm D}$ state--action pairs from visited keys and makes additional Q updates using the empirical model. Unvisited entries remain unknown. The learner neither copies evaluation truth nor fills in unobserved action outcomes. With $K_{\mathrm D}=0$ and identical initialization and random streams, Dyna-Q should reproduce Q-learning. Additional model updates are not new factual samples, but their computation is counted.

Tabular baselines characterize task-specific learning and empirical-model reuse, but do not by themselves establish an advantage of the PFN architecture. We therefore also include PPO trained from scratch with the same graph--Transformer architecture. This comparison evaluates the benefit of transferring cross-task experience while holding the policy architecture fixed.

\subsubsection{Inference Cost and Method Limitations}
The candidate output head replaces repeated deployment-time optimization with a network decision. Let $h$ be the embedding width, $L_g$ the number of graph layers, $L_T$ the number of Transformer layers, and $n_{\mathrm{tok}}$ the token count. The main computational cost is
\begin{equation}
O\!\left(L_g(|\mathcal E|h+Nh^2)
+L_T(n_{\mathrm{tok}}^2h+n_{\mathrm{tok}}h^2)+M C_{\mathrm{act}}\right),
\label{eq:complexity}
\end{equation}
where $C_{\mathrm{act}}$ is the cost of scoring one candidate. Static features can be cached, while dynamic node states and history require updates. The autoregressive variant additionally performs $N$ sequential decoding steps. Direct forward inference is therefore not strictly $O(1)$ in graph size. Enumerating all allocations can still produce an exponentially large catalog. A fixed catalog controls computation by restricting the action space, which also limits achievable policy quality.

Across $n$ deployment tasks, average amortized cost is
\begin{equation}
\overline C(n)=\frac{C_{\mathrm{train}}}{n}
+\frac1n\sum_{j=1}^n(C_{\mathrm{catalog},j}+C_{\mathrm{context},j}+C_{\mathrm{decision},j}).
\label{eq:amortized-cost}
\end{equation}
Training interactions, expert generation, catalog construction, and online inference are reported separately. The framework is intended to benefit repeated deployment across tasks, but the break-even task count and realized speedup require measurement.

\section{Experiments and Evaluation}
\label{sec:experiments}
The experiments evaluate whether a shared PFN policy can transfer useful allocation decisions to new network environments and use factual feedback efficiently. The main result is a consistent advantage over same-architecture PPO across the new-task learning curve. In cooldown environments, PFN also approaches the catalog-restricted oracle return after a small adaptation budget. Static allocation, online exploration, and known-model planning experiments provide complementary comparisons within the progressive framework.

\paragraph{Return and task normalization.}
The performance objective is the finite-horizon policy return in Equation~\eqref{eq:return}. For a preceding adaptation budget $b$, let $\widehat J_{\psi}(b)$ be the average, over five replicate seeds and eight evaluation episodes, of
\begin{equation}
\sum_{t=0}^{T-1}\gamma^t r_{\mathrm{env},\psi}(q_t,a_t).
\label{eq:empirical-mean-return}
\end{equation}
Here the evaluator replaces each executed action's noisy reward with its true conditional mean, while the policy continues to observe factual noisy feedback. Thus evaluation retains the actual feedback-dependent trajectories and reduces external reward noise. Observed-reward results are reported in Appendix~\ref{sec:supplementary-results}. We solve the true-model planning problem within the same catalog to obtain $J^*_{\psi,\mathrm{env}}>0$, and define the task-normalized return
\begin{equation}
s_{\psi}(b)=100\,\frac{\widehat J_{\psi}(b)}{J^*_{\psi,\mathrm{env}}}.
\label{eq:normalized-return}
\end{equation}
Every environment has equal weight: normalization is performed before averaging across the five environments. The reported dispersion is the sample standard deviation of task means. To summarize the full adaptation curve, we use
\begin{equation}
\mathrm{AUC}_{\psi}=\frac{1}{1200}\int_{0}^{1200}s_{\psi}(b)\,\mathrm db,
\label{eq:normalized-auc}
\end{equation}
computed by the trapezoidal rule on the eleven recorded evaluation points. This quantity measures average evaluation quality over the adaptation budget, rather than cumulative rewards collected while adapting.

\paragraph{New-task protocol.}
At $b=0$, the policy has no preceding adaptation records from the new task. It can use earlier feedback within the six-step evaluation episode. At later points, each evaluation episode starts from a private copy of the adaptation context, and its feedback is discarded after that episode. Separate evaluation streams add $11\times8\times6=528$ evaluation interactions per method--task--seed--dynamics combination; these interactions do not train the policy or carry into subsequent adaptation. PFN weights remain fixed throughout deployment. PPO from scratch has the same architecture and uses the same factual adaptation budget, with task-specific gradient updates. Training, validation, and test environment seeds are separated. All replicate seeds evaluate the same validation-selected pretrained checkpoint.

For a new CD task, exact score-based planning takes $17.35$ seconds including solution and episode action selection, while an adapted PFN's six action calls take $0.0324$ seconds in the recorded CPU-planner/accelerator-policy configuration. PFN thus moves substantial new-instance solution work into shared training. These costs distinguish a new planning problem from later reuse of an already solved DP table. Tabular lookups are inexpensive at this scale, while PFN provides much higher returns (Table~\ref{tab:learning}).

\paragraph{Preparation and first calls.}
Average graph/catalog generation, Ridge prediction, and combined score/environment caching take $5.61$, $3.87$, and $2.01$ ms per task, respectively. These preparation records are separate from method decision timers. Static catalog enumeration takes $0.008$ ms once all candidate scores are available. The static PFN's first recorded call in each of the eight worker processes averages $8.891$ seconds; the remaining $17$ calls average $5.303$ ms, with median $5.258$ ms and P95 $5.746$ ms. Reporting these two groups separately characterizes both first-call overhead and subsequent inference. The recorded first-call timers do not include full process and model-loading startup. Action-call timings throughout this section exclude environment stepping and external context bookkeeping.

\paragraph{Training investment and reuse.}
The selected sequential PFN checkpoint follows $50$ updates over $25{,}600$ training environments and $30{,}720{,}000$ factual interactions. Its cumulative timed training updates take $11{,}662.00$ seconds ($3.24$ hours). Selection uses validation return after $120$ adaptation interactions.
